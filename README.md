# GA_constrained_optimization

# Necessary steps to reproduce the optimization:

# 1.Download MATLAB R2016a version or newer
# 2.Download FEMM (https://www.femm.info/doku/doku.php?id=start)
# 3.Download and unzip both packages "GA_constrained_optimization-main" and "Motor_design-main" in the same path (e.g. C:\github)
# 4.Open C:\github\GA_constrained_optimization-main\GA_constrained_optimization-main\NEW_OPTIM  and replace the directory in line 5 with your directory (e.g. C:\github)
# 5.Run NEW_OPTIM
